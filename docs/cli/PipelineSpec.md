# PipelineSpec

`PipelineSpec` is a configuration (_specification_) of a pipeline.

## Creating Instance

`PipelineSpec` takes the following to be created:

* <span id="name"> name
* <span id="storage"> storage
* <span id="catalog"> catalog
* <span id="database"> database
* <span id="configuration"> configuration
* <span id="libraries"> libraries

`PipelineSpec` is created when:

* `cli.py` is requested to [unpack_pipeline_spec](cli.md#unpack_pipeline_spec)
