# SparkPipelines

`SparkPipelines` is a standalone application that is executed using [spark-pipelines](./index.md) shell script.

`SparkPipelines` is a Scala "launchpad" to execute [pyspark/pipelines/cli.py](cli.md) Python script (through [SparkSubmit]({{ book.spark_core }}/tools/spark-submit/SparkSubmit/)).
